## 🚀 Featured Projects

### 🧠 [Enhancing nnWNet via Multi-Scale Convolutional Attention for Biomedical Image Segmentation](https://github.com/yaswanth0702/nnWNet-via-Multi-Scale-Convolutional-Attention-for-2D-Biomedical-Image-Segmentation)
> PyTorch · Computer Vision · Medical Imaging · Attention Mechanisms

Integrated a **Multi-Scale Convolutional Attention (MSCA)** module into the nnWNet architecture (CVPR 2025) to improve 2D biomedical image segmentation. Evaluated on DRIVE (retinal vessels) and ISIC-2017 (skin lesions).
- Improved Dice score from 0.62 → **0.73** on ISIC-2017
- Reduced boundary error (ASD) from 19.71 → **14.46**
- Used parallel depthwise convolutions (7×7, 11×11, 15×15) for multi-scale feature extraction
